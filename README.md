# Lost in the Repository

[![Tests](https://github.com/Ankan0503/lost-in-the-repository/actions/workflows/tests.yml/badge.svg)](https://github.com/Ankan0503/lost-in-the-repository/actions/workflows/tests.yml)

**Lost in the Repository** is a spooky, silly command-line choose-your-own-adventure game. You are a first-time open source contributor trapped in a haunted GitHub repository. Find your way through merge-conflict monsters, a stale-branch graveyard, and a grumpy maintainer ghost to get your first pull request merged before Hacktoberfest ends.

```text
+--------------------------------------------------------------------------+
|                         LOST IN THE                                      |
|                           REPOSITORY                                     |
+--------------------------------------------------------------------------+

The Foggy Graveyard of Stale Branches
Branches poke from the fog like crooked headstones: feature/final-final-2 and
actually-done-this-time. A brass repository key glints among the roots while
merge-conflict monsters growl between them.
  1. Light the fog with your lantern [needs lantern]
  2. Run blindly toward the workshop
  3. Let the branches have your username

>
```

## Features

- JSON graph keeps story content separate from the Python engine.
- Inventory items unlock routes and secret content.
- Four endings: one good, two bad, and one secret ending.
- Typewriter text, ANSI colors, ASCII title art, and Windows terminal support.
- Save/resume progress and persistent ending discovery.
- Standard library only, with `unittest` coverage for graph links, inventory-aware
ending reachability, ending types, secret-item gating, save/load round trips,
ending totals, inventory logic, and input parsing.

## Run

```text
python adventure.py
```

The game resolves `story.json`, `savegame.json`, and `endings.json` beside
`adventure.py`, so it can also be launched from another folder with a path
such as `python path/to/adventure.py`.

Flags:

- `--fast` disables the typewriter effect.
- `--no-color` disables ANSI colors.
- `--load` resumes from the save beside `adventure.py`; an invalid or missing
  save starts a fresh game.

## How to play

Choose a numbered option. Locked options are dimmed and show the required item. During play, use `i` for inventory, `s` to save, `h` for help, and `q` to quit. When you reach an ending, the game records it in `endings.json` and offers a replay.

## How this was built

Made for the MLH Global Hack Week: Open Source challenge *Use GitHub Copilot to
Build a Simple Application*.

- All game code, story content, and tests were generated by
  [GitHub Copilot CLI](https://github.com/github/copilot-cli) (v1.0.95) in two
  non-interactive runs.
- The CI workflow was added by GitHub Copilot CLI in an interactive session.
- The prompts were written, and Copilot's output was reviewed and play-tested,
  with help from Claude Code. Problems found while play-testing (a missing fourth
  ending, crashes on Ctrl+C and when launched from another folder, garbled title
  art, weak reachability tests) were sent back to Copilot as a second prompt
  rather than fixed by hand.
- The full Copilot sessions, including the exact prompts, are exported in
  `docs/`:
  - [`docs/copilot-session-1-build.md`](docs/copilot-session-1-build.md): the
    initial build
  - [`docs/copilot-session-2-fixes.md`](docs/copilot-session-2-fixes.md): the
    play-test fixes
